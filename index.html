Chọn file Excel để xem dashboard

Kéo thả file .xlsx vào đây, hoặc bấm nút bên dưới.
Ứng dụng đọc tất cả các sheet ngay trên máy bạn, dữ liệu không bị gửi đi đâu.

Hoặc bấm “⚙ GitHub” để kết nối kho dữ liệu riêng tư và tự động tải file Excel nguồn.

Kết nối GitHub

Dashboard đọc/ghi file Excel nằm trong repo dữ liệu riêng tư của bạn. Mã truy cập chỉ lưu trong trình duyệt này.
